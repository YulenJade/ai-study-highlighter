# Roadmap

V0.4 implements provisioned private accounts, five-format text extraction, larger books, external PostgreSQL/S3 persistence, quota/failure recovery, PDF regression tests and deployment documentation.

Next: isolated no-network parser workers and malware scanning; durable asynchronous jobs and resumable direct uploads with server-side validation; OAuth/account recovery and distributed abuse controls; OCR; semantic matching with explicit evidence and user opt-in; Office annotation/export; administrator cleanup/audit and schema migration tooling.

There is no live hosted deployment implied by the repository. External infrastructure must be configured and acceptance-tested.
