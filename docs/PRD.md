# Product requirements / 产品需求

## MVP
1. Upload a text-based PDF / 上传文字型 PDF
2. Enter one literal phrase per line / 每行输入一个需要匹配的原文短语
3. Highlight verified exact matches / 只高亮 PDF 中真实存在的匹配文字
4. Download a separate annotated PDF / 下载独立副本

## Acceptance / 验收
- Source PDF remains unchanged / 原始 PDF 不变
- Repeated phrases may create multiple highlights / 重复词句可能生成多处高亮
- Invalid PDFs and oversized files rejected / 拒绝非法或超大文件
- No hallucinated citations or page numbers / 不生成虚构引文与页码

## Not implemented / 尚未实现
AI semantic matching, OCR, Notion OAuth, multi-user authentication, payment, automated delivery.
